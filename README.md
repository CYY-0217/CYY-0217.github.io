# 陈韵韵个人作品集

面向比赛报名展示的静态作品集网站，可直接部署到 GitHub Pages。

## 本地预览

```bash
python3 -m http.server 4198
```

访问 `http://127.0.0.1:4198/`。

## 推荐 GitHub 仓库

仓库名必须为 `CYY-0217.github.io`，部署后主页地址为 `https://cyy-0217.github.io/`。

## 内容边界

- 聚变项目个人职责依据工作总结与 Unity 开发记录提炼。
- PINNs 作为项目整体技术路线呈现，没有将全部模型研发归为个人成果。
- 奖项仅写为“省级奖项”，待补充正式名称、年份和证书后更新。
- 当前未使用个人照片；可在后续补充正式头像、项目实机截图、获奖照片和简历 PDF。
