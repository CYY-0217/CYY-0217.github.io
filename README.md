# 陈韵韵个人作品集

面向比赛报名展示的静态作品集网站，可直接部署到 GitHub Pages。

当前版本采用简约杂志风，采用莫兰迪配色：暖纸白背景，灰绿、米杏、灰紫与豆沙色；以用户提供的原卡片截图为参考，保留上方视觉区、下方同色系内容区和宋体标题、细线分栏、克制留白；保持横平竖直，图片与界面元素不倾斜、不旋转，使用直角网格。真实项目图片保留原色。主页按四个方向组织六个项目，并加入工作方法、阶段复盘、随滚动更新的分类导航和可折叠手机菜单。

## 设计约束与精修

- 以用户确认的莫兰迪卡片截图为基准，保留上下分区、同色系背景、宋体标题、直角与细线，不改为其他视觉风格。
- 封面和正文共用内边距；双卡片封面标题、正文和底部状态与入口对齐。手机端保持同一条内容左边线。
- 分类栏紧接顶栏固定，避免两栏之间露出上一项目内容；焦点边框与分类高亮支持键盘浏览。

## 项目分类

| 方向 | 项目 | 展示入口 |
| --- | --- | --- |
| 专业工程与 XR | 智探新能 | 项目案例与公开交互脚本 |
| AI 与个人成长 | GrowLab、Idea Incubator、50 Day Discipline | 前两项链接公开仓库；打卡器保留早期案例 |
| 生活决策工具 | 我想花钱 | 产品案例与浏览器本地演示 |
| 互动叙事与内容 | Wanderlogue | 案例与在线互动杂志 |

50 Day Discipline 是 GrowLab 的前身，两个条目共同呈现从打卡工具到成长 Agent 的演进。Idea Incubator 为 PC 本地应用，尚未作为多用户在线产品部署。
